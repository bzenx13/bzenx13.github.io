Foire aux questions (FAQ)

Qu'est-ce qu'une étiquette électronique ?
C'est un objet utilisé principalement dans les grandes surfaces et les pharmacies pour afficher dynamiquement les prix et transmettre d'autres informations logistiques.
Comment fonctionne le système de menu déroulant ?
Il utilise la balise HTML native <details> combinée avec <summary>, ce qui évite d'avoir à écrire du code JavaScript complexe pour gérer l'ouverture et la fermeture.
